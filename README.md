# blog-api
This project is using an API only back-end and two different front-ends. One of the front-end sites will be for people that want to read and comment on posts and the other one will be just for writing, editing and publishing posts.

Live links:

Frontend-reader: https://blog-api-frontend-reader-chi.vercel.app

Frontend-editor: https://blog-api-frontend-editor.vercel.app
